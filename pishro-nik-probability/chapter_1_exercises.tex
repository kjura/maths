\section*{Problem 8*}

Niech \(x \in A\). Istnieje wtedy \(n_0 \in \mathbb{N}\) takie, że \(0 \leq x < 1 - \frac{1}{n_0} < 1\). Stąd \(x \in [0, 1)\).
W drugą stronę, niech \(x \in [0, 1)\). Wiadomym jest, że \(\lim_{n \to \infty} 1 - \frac{1}{n} = 1\). Zauważmy, że
\( \frac{1 - x}{2} > 0 \). Z definicji granicy ciągu istnieje zatem \(n_0 \in \mathbb{N}\) takie, że:
\begin{equation*}
    |\big(1 - \frac{1}{n}\big) - 1| = \frac{1}{n} < \frac{1 - x}{2} \ \ \mbox{dla} \ \ n \geq n_0
\end{equation*}
Stąd:
\begin{equation*}
    0 \leq x < 1 - \frac{2}{n} < 1 - \frac{1}{n} < 1 \ \ \mbox{dla} \ \ n \geq n_0
\end{equation*}
i stwierdzamy, że \(x \in A\).
\subsection*{Appendix}
W drugą stronę (bez analizy). Szukamy \(n \in \mathbb{N}\) takiego, że \(x < 1 - \frac{1}{n}\). Mamy zatem:

\begin{equation*}
    x < 1 - \frac{1}{n} \iff \frac{1}{n}  < 1 - x \iff \frac{1}{1 - x} < n 
\end{equation*}
Zatem dla \(x \in [0, 1)\) istnieje \(n > \frac{1}{1 - x}\) gdzie \(x \in A_{n}\). Stąd \(x \in A\).

\section*{Problem 9*}

First, observe that \( 0 < \frac{1}{n} \) for every \(n \geq 1\) and \(0\) is in every \(A_n\). Then \( 0 \in A \).
\newline
It is known that \(A \subseteq [0, \infty)\). Indeed, if \(a \in A\) then:
\begin{equation*}
    (\forall n \geq 1) \ \ a \in A_{n} \implies a \in A_{1} = [0, 1) \implies a \in [0, 1] \implies a \in [0, \infty)
\end{equation*}

Assume now that \(a > 0\). We know that \(\lim_{n \to \infty} \frac{1}{n} = 0\).
Let \(\epsilon = a\).  From the definition of the limit there exists \(n_0 \in \mathbb{N}\) such that:

\begin{equation*}
    a = \epsilon > |\frac{1}{n} - 0| = |\frac{1}{n}| = \frac{1}{n} \ \ \mbox{dla} \ \ n \geq n_0
\end{equation*}

Then:

\begin{equation*}
    a > \frac{1}{n} > 0 \ \ \mbox{dla} \ \ n \geq n_0
\end{equation*}

We have \(a \notin A_{n_0}\). Using contraposition:

\begin{equation*}
    \Big( a \notin \{0\} \implies a \notin A \Big) \iff \Big( a \in A \implies a \in \{0\} \Big)
\end{equation*}

and finally we have:

\begin{equation*}
    A = \bigcap_{n=1}^{\infty} [0, \frac{1}{n}) = \{ 0 \}
\end{equation*}

\section*{Problem 15*}

Our \(\Omega\) is a set of 2-D vectors indicating a result of two throws, first coordinate is the first throw and the second
is the second throw e.g \((1, 2), (4, 6), (2, 3)\) etc. \(\Omega = 36\).

\subsection*{a.}
If \(X_2 = 4\) it means we seek vectors with \(4\) as a second coordinate i.e \((a, 4)\) where \(a \in \{1..6\}\). There are \(6 * 1 = 6\) possible
combinations therefore:

\begin{equation*}
    P(X_2 = 4) = \frac{6}{36} = \frac{1}{6}
\end{equation*}

\subsection*{b.}
We want to find throws obeying \(X_1 + X_2 = 7\). We can point \((1, 6), (2, 5), (3, 4)\) and their reverse so in total
we have \(6\) combinations. We have again:

\begin{equation*}
    P(X_1 + X_2 = 7) = \frac{6}{36} = \frac{1}{6}
\end{equation*}

\subsection*{c.}
For \(X_1 \neq 2\) we can find vectors like \((\mbox{\{1, 3, 4, 5, 6\}}, \mbox{\{1, 2, 3, 4, 5, 6\}})\) (curly brackes indicate a possible element e.g \((3, 6)\))
which gives us \(5 * 6 = 30\) combinations. For \(X_2 \geq 4\) we can find vectors \((\mbox{\{1, 2, 3, 4, 5, 6\}}, \mbox{\{4, 5, 6\}})\) which in total
give \(6 * 3 = 18\) combinations. Now, we need to take the intersection of these two events. We want to take vectors with the following form:

\begin{equation*}
    (1, 4), (3, 4), (4, 4), (5, 4), (6, 4), (1, 5), (3, 5), (4, 5), \dots , (1, 6), (3, 6), \dots, (6, 6)
\end{equation*}

that is we are skipping \(2\) in the first position and taking \(4, 5, 6\) in the second position. We have:

\begin{equation*}
    P\Big( (X_1 \neq 2) \cap (X_2 \geq 4) \Big) = \frac{15}{36} = \frac{5}{12}
\end{equation*}


\subsection*{Appendix}
In section (a.) we could have ignored the first throw, because dice throws are independent, skipping straight to
\(P(X_2 = 4) = \frac{1}{6}\).

\subsection*{a.}

The sample space \(S = \{1, 2, 3, \dots\}\) is a countable set. Since \(P(S) = 1\)
by the third axiom of probability we can write:

\begin{equation*}
    P(S) = P(\{1, 2, 3, \dots\}) = P(\bigcup_{s_{j} \in S} \{s_j\}) = \sum_{s_{j} \in S}P(s_{j}) = 1
\end{equation*}
Next, we can use natural indices to represent above:
\begin{equation*}
    \sum_{s_{j} \in S}P(s_{j}) = \sum_{k=1}P(k)  = \sum_{k=1} \frac{c}{3^{k}} = c \sum_{k=1} \Big(\frac{1}{3}\Big)^{k} = 1
\end{equation*}

We seek:
\begin{equation*}
    c = \frac{1}{\sum_{k=1} \Big(\frac{1}{3}\Big)^{k}}
\end{equation*}

We quickly recognize that \(\sum_{k=1} \frac{1}{3^{k}}\) is a geometric series. Using the series sum:
\begin{equation*}
    \sum_{k=1} \Big(\frac{1}{3}\Big)^{k} = \Big( 1 + \frac{1}{3} + \Big(\frac{1}{3}\Big)^{2} + \Big(\frac{1}{3}\Big)^{3} + \dots \Big) - 1
\end{equation*}
\begin{equation*}
    = \Big(\frac{1}{1 - \frac{1}{3}}\Big) - 1 = \Big(\frac{1}{\frac{2}{3}}\Big) - 1 = \frac{3}{2} - 1 = \frac{1}{2}
\end{equation*}
So finally:
\begin{equation*}
    c = \frac{1}{\frac{1}{2}} = 2
\end{equation*}
