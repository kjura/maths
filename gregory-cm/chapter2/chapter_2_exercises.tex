\section*{2.1}

Let us indicate the displacement of the \(P\) particle as:
\begin{equation*}
    x(t) = 6t^{2} - t^{3} + 1
\end{equation*}
where \(x\) is measured in metres and \(t\) in seconds. The velocity and acceleration can be found
by calculcating the first and second derivative respectively:

\begin{equation*}
    v(t) = \dv{x}{t} = 12t - 3t^{2} = -3t^{2} + 12t
\end{equation*}
\begin{equation*}
    a(t) = \dv{v}{t} = -6t + 12
\end{equation*}


\(P\) is at rest when its velocity equals zero. We immediately set up a necessary equation:
\begin{equation*}
    v(t) = 0 \implies -3t^{2} + 12t = 0
\end{equation*}
\begin{equation*}
    3t(4 - t) = 0
\end{equation*}

We have found two times at which \(P\) is at rest: \(t_1 = 0s\) and \(t_2 = 4s\). We will conclude with
calculcating the position of \(P\) at these times:
\begin{equation*}
    x(0) = 6 \cdot 0^2 - 0^{3} + 1 = 1m
\end{equation*}
\begin{equation*}
    x(4) = 6 \cdot 4^{2} - 4^{3} + 1 = 96 - 64 + 1 = 33m
\end{equation*} 


\section*{2.2}

To find the velocity and displacement of P we will first integrate the acceleration and then
integrate once more to get P's displacement.
One obtains:

\begin{equation*}
    v(t) = \int a(t) dt = \int 6t - 4 dt = 3t^{2} -4t + C_1
\end{equation*}
\begin{equation*}
    x(t) = \int v(t) dt = \int 3t^{2} -4t + C_1 dt = t^{3} - 2t^{2} + C_{1}t + C_2
\end{equation*}

We use provided initial conditions to get the underlying values of the constants \(C_1\) and \(C_2\):
\begin{equation*}
    x(0) = 20m
\end{equation*}
\begin{equation*}
    v(0) = -15ms^{-1}
\end{equation*}

which means:

\begin{equation*}
    -15ms^{-1} = 3\cdot0^{2} - 4 \cdot 0 + C_1 = C_1
\end{equation*}
\begin{equation*}
    20m = 0^{3} - 2 \cdot 0^{2} + C_{1} \cdot 0 + C_2 = C_2 
\end{equation*}

So the full formulas are now:

\begin{equation*}
    v(t) = 3t^{2} -4t - 15
\end{equation*}
\begin{equation*}
    x(t) = t^{3} - 2t^{2} -15t + 20
\end{equation*}

P comes to rest when its velocity is equal to zero, we set up the necessary equation:

\begin{equation*}
    v(t) = 0 \iff 3t^{2} -4t - 15 = 0
\end{equation*}
\begin{equation*}
    3(t-3)(t + \frac{5}{3}) = 0
\end{equation*}
We exclude \(t < 0\) because t must be greater than or equal to zero.
There is one point in time at which P stops, \(t_1 = 3s\). The displacement
of P at this time is:
\begin{equation*}
    x(t_1=3) = 3^{3} - 2 \cdot 3^{2} -15 \cdot 3 + 20 = -16m
\end{equation*}
which indicates that P moved in the negative x-direction.

\section*{2.3}
Let's assume without loss of generality that the origin is a point at zero.
From provided initial conditions, \(v(0) = u\) and \(x(0) = 0\).
We can view the velocity
as the integral of the acceleration and the displacement as the integral of the velocity w.r.t. time:

\begin{equation*}
    v = \int a dt = a \int dt = a \cdot (t + C) = at + aC = at + C_{1}
\end{equation*}
\begin{equation*}
    x = \int v dt = \int at + C_1 dt = \frac{1}{2}at^{2} + C_{1}t + C_{2}
\end{equation*}
Using the initial conditions one receives:

\begin{equation*}
    u = v(0) = a \cdot 0 + C_{1} = 0 + C_{1} = C_{1}
\end{equation*}
and knowing now \(C_{1}\) we get:
\begin{equation*}
    0 = x(0) = \frac{1}{2}a \cdot 0^{2} + u \cdot 0 + C_{2} = 0 + 0 + C_{2} = C_{2}
\end{equation*}
So the complete formulas look like:
\begin{equation*}
   x = \frac{1}{2}at^{2} + ut
\end{equation*}
\begin{equation*}
   v = at + u
\end{equation*}
Let us now eliminate time from the formula for the displacement by using the formula for \(v\):

\begin{equation*}
    \frac{v - u}{a} = t
\end{equation*}
\begin{equation*}
    x = \frac{1}{2}at^{2} + ut = \frac{1}{2}a (\frac{v - u}{a})^{2} + u(\frac{v - u}{a})
\end{equation*}
\begin{equation*}
    = \frac{1}{2}a \frac{v^{2} - 2vu + u^{2}}{a^2} + \frac{uv - u^2}{a}
\end{equation*}
\begin{equation*}
    = \frac{v^{2} - 2vu + u^{2}}{2a} + \frac{2uv - 2u^2}{2a} = 
\end{equation*}
\begin{equation*}
    = \frac{v^{2} - 2vu + u^{2}}{2a} + \frac{2uv - 2u^2}{2a} = \frac{v^{2} - u^{2}}{2a}
\end{equation*}

And finaly we get the formula for the squared velocity:
\begin{equation*}
    v^2 = 2ax + u^{2}
\end{equation*}

Consider now the Suzuki Bandit case. Assume the acceleration is constant and eliminate
\(a\) from the displacement formula:

\begin{equation*}
    \frac{v - u}{t} = a
\end{equation*}
\begin{equation*}
    x = ut + \frac{1}{2}\frac{v - u}{t}t^{2} = ut + \frac{1}{2}(v - u)t
\end{equation*}

Since the initial velocity is zero our formula takes a form of:
\begin{equation*}
    0.25mi = \frac{1}{4}mi = \frac{1}{2} \cdot 116 \cdot 11.4 \cdot \frac{1}{3600} mi
\end{equation*}
\begin{equation*}
    0.25mi = \frac{1}{4}mi \approx 0.1836 mi
\end{equation*}

which gives the relative error w.r.t to the original value measured around \(25 \% \). This is not
consistent with the assumption of constant acceleration hence the assumption was wrong.
